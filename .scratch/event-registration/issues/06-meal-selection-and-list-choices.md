# 06: 參與者餐點選擇與名單顯示

**What to build:** 出席的參與者能在同一頁針對每個餐點群組各選一項（或留空選填群組），不出席時這些選項自動收起；名單上能看到每個人的選擇。

**Blocked by:** 05（選項群組管理與複製活動）

**Status:** ready-for-agent

- [ ] 報名表單依排序渲染所有啟用中的自訂群組；必填群組標示必填
- [ ] 選填群組提供明確的「不選」，未選時不建立選擇資料
- [ ] 選擇「不出席」時前端隱藏自訂群組，後端也忽略送來的自訂選擇；切回出席可重新選擇
- [ ] 必填群組缺漏時拒絕送出，指出缺少的群組並保留其他輸入
- [ ] 送出後為每個群組儲存選項、群組標題與選項文字快照
- [ ] 覆蓋報名時正確更新選擇；改為不出席時清除所有自訂選擇
- [ ] 名單顯示每個人的各群組選擇
- [ ] 已停用但曾被選擇的選項在名單以「（已停用）」呈現
- [ ] 已停用選項不出現在表單；選擇已停用或不屬於本活動的選項會被拒絕
- [ ] 沒有 JavaScript 時仍可完成報名（隱藏僅是體驗優化）
