# 07: 名單統計與手機版體驗

**What to build:** 名單頁最上方顯示出席率與各餐點數量，讓主辦者一眼知道要訂幾份；參與者在手機上以卡片閱讀名單，頁面每 30 秒自動更新。

**Blocked by:** 06（參與者餐點選擇與名單顯示）

**Status:** done

- [x] 名單頁顯示總筆數、出席數、不出席數、出席率（整數百分比；0 筆時顯示「—」）
- [x] 每個群組顯示各選項人數與佔該群組作答人數的比例
- [x] 停用但有歷史選擇的選項列入統計並標示「已停用」
- [x] 選填群組顯示「未選」人數
- [x] 統計即時由資料庫計算，不快取
- [x] 桌機以表格、寬度小於 768px 以卡片呈現
- [x] 頁面每 30 秒自動更新
- [x] 提供「回報名頁」與「結束」按鈕，兩者皆導回報名頁，不使用 window.close()
- [ ] 名單不含聯絡資訊
