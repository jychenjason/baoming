# 05: 選項群組管理與複製活動

**What to build:** 管理員能在活動中建立「主餐」「飲料」這類單選群組、調整順序與必填狀態，也能停用不再提供的選項；並能把整個活動連同選項複製成下一次聚餐的起點。

**Blocked by:** 04（報名、同名覆蓋、預填與基本名單）

**Status:** done

- [x] 管理員可新增、編輯、排序自訂群組，設定標題與必填／選填
- [x] 管理員可新增、編輯、排序、停用選項；已被報名使用的選項不可直接改名，須停用舊選項並新增替代選項；停用前需二次確認並說明既有報名會保留
- [x] 停用選項標記為不可供新報名使用，但歷史資料保留（公開表單呈現由 06 完成；本 ticket 實作資料狀態與管理介面）
- [x] 出席群組不可刪除、改名、停用，且固定為必填
- [x] 群組與選項文字長度依規格驗證；錯誤時保留輸入
- [x] 同一活動內群組標題按 NFKC、空白正規化及 casefold 後不得重複
- [x] 已被報名選取的選項保留歷史快照；群組／選項管理不改寫既有選擇快照，可停用舊選項並新增替代選項
- [x] 可複製既有活動：標題加註「（複本）」、複製說明、地點、時間、群組與選項，狀態為 `draft`，不含任何報名資料
- [x] 管理操作皆具 CSRF；未登入導向登入頁
