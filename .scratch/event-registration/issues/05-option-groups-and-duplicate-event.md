# 05: 選項群組管理與複製活動

**What to build:** 管理員能在活動中建立「主餐」「飲料」這類單選群組、調整順序與必填狀態，也能停用不再提供的選項；並能把整個活動連同選項複製成下一次聚餐的起點。

**Blocked by:** 04（報名、同名覆蓋、預填與基本名單）

**Status:** ready-for-agent

- [ ] 管理員可新增、編輯、排序自訂群組，設定標題與必填／選填
- [ ] 管理員可新增、編輯、排序、停用選項；停用前需二次確認並說明既有報名會保留
- [ ] 停用選項不出現在公開表單，但歷史資料保留（公開表單於 06 完成；本 ticket 以資料狀態與管理介面驗證）
- [ ] 出席群組不可刪除、改名、停用，且固定為必填
- [ ] 群組與選項文字長度依規格驗證；錯誤時保留輸入
- [ ] 同一活動內群組標題按 NFKC、空白正規化及 casefold 後不得重複
- [ ] 已被報名選取的選項保留歷史快照；改供新答案時停用舊選項並新增，不直接改寫舊答案文字
- [ ] 可複製既有活動：標題加註「（複本）」、複製說明、地點、時間、群組與選項，狀態為 `draft`，不含任何報名資料
- [ ] 管理操作皆具 CSRF；未登入導向登入頁
