# 04: 報名、同名覆蓋、預填與基本名單

**What to build:** 參與者輸入姓名、選擇出席或不出席即可完成報名，送出後立刻看到名單；同名再次送出時會被詢問是否覆蓋；重新開啟連結時看到上次填的內容。

**Blocked by:** 03（數學驗證與活動資訊頁）

**Status:** ready-for-agent

- [ ] 報名頁提供姓名輸入與出席／不出席單選，兩者皆必填
- [ ] 姓名長度與空白驗證；錯誤時同頁顯示訊息並保留其他輸入
- [ ] 姓名以 NFKC、去前後空白、合併連續空白、Latin 字母 casefold 正規化後比對
- [ ] 首次送出建立報名，導向名單頁
- [ ] 同名送出時顯示覆蓋確認頁並列出目前資料；確認後更新同一筆、保留建立時間、更新最後更新時間
- [ ] 取消覆蓋回到表單並保留原輸入
- [ ] 以簽章 cookie 記住本活動的報名；重開連結時預填姓名與出席狀態
- [ ] 名單頁顯示姓名、出席狀態、總筆數、出席數與不出席數，依建立時間排序
- [ ] 名單頁與報名表皆需先通過數學驗證
- [ ] 非 `open` 狀態拒絕送出並顯示對應訊息
- [ ] 表單具 CSRF；報名送出限速為每 IP 每分鐘 20 次
- [ ] 名單不顯示聯絡資訊或 IP
