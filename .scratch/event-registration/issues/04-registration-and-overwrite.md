# 04: 報名、cookie 授權修改、預填與基本名單

**What to build:** 參與者輸入姓名、選擇出席或不出席即可完成報名，送出後立刻看到名單；只有持有原報名 cookie 的瀏覽器可確認修改同一筆；重新開啟連結時看到上次填的內容。

**Blocked by:** 03（數學驗證與活動資訊頁）

**Status:** done

- [x] 報名頁提供姓名輸入與出席／不出席單選，兩者皆必填
- [x] 姓名長度與空白驗證；錯誤時同頁顯示訊息並保留其他輸入
- [x] 姓名以 NFKC、去前後空白、合併連續空白、Latin 字母 casefold 正規化後比對
- [x] 首次送出建立報名，導向名單頁
- [x] 同名且 cookie 綁定該報名時顯示覆蓋確認；確認後更新同一筆、保留建立時間、更新最後更新時間
- [x] 無對應 cookie 的同名送出不洩露資料、不提供覆蓋，只提示聯絡管理員
- [x] cookie 遺失或跨裝置時由管理員協助；管理員改名後 cookie 仍綁定原報名 ID
- [x] 兩筆並行同名建立時唯一性衝突不覆蓋資料，回傳一般同名提示
- [x] 以簽章 cookie 記住本活動的報名；重開連結時預填姓名與出席狀態
- [x] 名單頁顯示姓名、出席狀態、備註、總筆數、出席數與不出席數，依建立時間排序
- [x] 名單頁與報名表皆需先通過數學驗證
- [x] 非 `open` 狀態拒絕送出並顯示對應訊息
- [x] 表單具 CSRF；報名送出限速為每 IP 每分鐘 20 次
- [x] 名單不顯示聯絡資訊或 IP；報名頁及名單頁告知活動連結持有者可見欄位並提醒備註勿填敏感資訊
