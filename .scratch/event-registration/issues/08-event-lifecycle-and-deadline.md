# 08: 活動生命週期與截止

**What to build:** 管理員能依現場狀況開放、關閉或重新開放活動；截止時間一到，系統就停止收單，但名單仍可查看。

**Blocked by:** 04（報名、同名覆蓋、預填與基本名單）

**Status:** ready-for-agent

- [ ] 管理員可手動開放、關閉與重新開放活動
- [ ] 截止時間到達後，任何送出都被拒絕並顯示「本活動已截止報名」；名單仍可讀
- [ ] 截止判斷使用伺服器時鐘（可注入），不依賴前端倒數或背景排程
- [ ] `draft` 狀態不可報名，公開頁顯示「尚未開放」
- [ ] 重新開放後可再報名；原截止時間保留，除非管理員修改
- [ ] 管理員修改截止時間後行為一致
- [ ] 狀態切換在活動列表與公開頁立即反映
