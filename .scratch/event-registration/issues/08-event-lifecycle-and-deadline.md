# 08: 活動生命週期與截止

**What to build:** 管理員能依現場狀況開放、關閉或重新開放活動；截止時間一到，系統就停止收單，但名單仍可查看。

**Blocked by:** 04（報名、同名覆蓋、預填與基本名單）

**Status:** done

- [x] 管理員可手動開放、關閉與重新開放活動
- [x] 開放前驗證每個自訂群組至少有兩個啟用選項，必填群組具可選答案；草稿可暫時不完整
- [x] 截止時間到達後，任何送出都被拒絕並顯示「本活動已截止報名」；名單仍可讀
- [x] 截止判斷使用伺服器時鐘（可注入），不依賴前端倒數或背景排程
- [x] `draft` 狀態不可報名，公開頁顯示「尚未開放」
- [x] 重新開放後保留原截止時間；截止已過時需先修改截止時間
- [x] 管理員可修改活動欄位及截止時間，時間輸入與顯示使用台北時間
- [x] 狀態切換在活動列表與公開頁立即反映
