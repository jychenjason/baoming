# 03: 數學驗證與活動資訊頁

**What to build:** 參與者打開活動連結時，先回答一題簡單加法，答對後才能看到活動資訊；這是唯一的「登入」，用來擋機器人而不是辨識身分。

**Blocked by:** 02（管理員登入、活動建立與公開連結）

**Status:** done

- [x] 未通過驗證時，活動連結只顯示數學題，不顯示任何報名表
- [x] 題目為二位數＋一位數且和 ≤ 100；答案存在伺服器端簽章 session，不以明文出現在 HTML
- [x] 題目產生器可注入，讓測試能指定題目與答案
- [x] 答錯時顯示提示並產生新題；答對後該瀏覽器 24 小時內免再答
- [x] 通過後顯示活動標題、時間、地點、說明與報名截止時間
- [x] 狀態為 `draft` 顯示「尚未開放」、`closed` 顯示「已截止」；`open` 提供報名入口（表單由 04 提供）
- [x] 無效 token 回 404
- [x] 數學題送出限速為每 IP 每分鐘 20 次，超過回 429
