# 10: CSV／JSON 匯出

**What to build:** 主辦者能把報名資料交給訂餐店家或做離線統計：CSV 用 Excel 直接開，JSON 保留完整結構。

**Blocked by:** 06（參與者餐點選擇與名單顯示）

**Status:** ready-for-agent

- [ ] CSV 以 UTF-8 BOM 輸出，Excel 可直接開啟且中文不亂碼
- [ ] CSV 欄位為姓名、出席狀態、備註、建立時間、最後更新時間，之後每個群組一欄
- [ ] 停用選項在 CSV 中的值加註「（已停用）」
- [ ] CSV 正確跳脫逗號、引號與換行
- [ ] CSV 對可能被試算表解讀為公式的儲存格做安全處理；JSON 保留原文
- [ ] JSON 匯出包含活動、群組、選項與所有報名，結構完整
- [ ] 兩種匯出皆僅限管理員；未登入導向登入頁
- [ ] 匯出時間以 Asia/Taipei 呈現
