# 09: 管理員報名維運

**What to build:** 主辦者能修正誤填、移除重複、或替電話報名的人補登資料，不必請對方重填。

**Blocked by:** 06（參與者餐點選擇與名單顯示）

**Status:** done

- [x] 管理員可在活動名單頁刪除單筆報名，操作前二次確認
- [x] 管理員可代為新增報名，欄位與參與者表單相同驗證（含姓名唯一性）；新增遵守活動開放狀態與截止時間
- [x] 管理員可代為修改姓名、出席、各群組選擇與備註；即使活動關閉仍可修正既有報名
- [x] 代改姓名與既有報名衝突時拒絕並提示
- [x] 修改後名單與統計立即反映
- [x] 管理操作具 CSRF；未登入導向登入頁
