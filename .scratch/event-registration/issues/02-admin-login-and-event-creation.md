# 02: 管理員登入、活動建立與公開連結

**What to build:** 主辦者能用單一密碼登入後台、建立第一個活動，並取得一組可傳給參加者的秘密連結；在活動尚未開放時，連結禮貌地告訴訪客「尚未開放」，無效連結則回 404。

**Blocked by:** 01（走路骨架與測試基座）

**Status:** done

- [x] 管理員以環境變數中的密碼登入，密碼以常數時間比較；錯誤時顯示「密碼錯誤」，不洩漏其他資訊
- [x] 登入 session 12 小時後失效；登出清除目前瀏覽器 cookie；密碼輪替使舊 session 失效
- [x] 未登入存取任何管理路由一律導向登入頁
- [x] 同一 IP 每分鐘超過 5 次登入失敗回 429
- [x] 所有管理表單含 CSRF token；缺少或錯誤回 400
- [x] 活動列表顯示標題、狀態、報名數、截止時間與可複製的公開連結
- [x] 可建立活動並填寫標題（必填）、說明、地點、開始時間、報名截止時間；長度依規格驗證且錯誤時保留輸入
- [x] 建立活動時自動產生不可刪除、固定必填的出席群組，以及「出席」「不出席」兩個固定選項
- [x] 新活動狀態為 `draft`；開啟公開連結顯示「活動尚未開放」
- [x] 不存在的活動 token 回 404
- [x] 可重新產生公開連結 token，舊連結立即失效
- [x] session cookie 具 HttpOnly、SameSite=Lax，偵測到 HTTPS 時加上 Secure
